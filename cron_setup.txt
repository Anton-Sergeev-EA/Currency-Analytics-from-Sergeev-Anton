# Currency Analytics - настройка cron для автоматического обновления курсов валют
# Установка: crontab -e, затем вставить следующие строки:
#
# ВАЖНО (изменилось после аудита безопасности): /api/force-refresh теперь
# требует заголовок X-Admin-Key со значением SECRET_KEY из .env - раньше
# этот эндпоинт был открыт всему интернету без какой-либо проверки, любой
# мог его дёргать и грузить CBR/CPU на VDS. Установи значение своего
# SECRET_KEY один раз переменной окружения crontab (строка ниже, до самих
# заданий) - crontab поддерживает такие "VAR=value" строки, они действуют
# на все задания после себя:
CURRENCY_ANALYTICS_ADMIN_KEY=paste_your_real_SECRET_KEY_from_.env_here
#
# Пути в логах ниже (/root/currency-analyzer/...) не совпадают с реальным
# именем каталога деплоя в этом репозитории
# (Currency-Analytics-from-Sergeev-Anton) - это уже было так до этого
# аудита; не трогала, чтобы не сломать то, что у тебя реально настроено.
# Если у тебя каталог называется иначе - поправь пути ниже под себя.
#
# ПОРТ 8002, а не 8000: docker-compose.yml публикует контейнер на хосте
# как "8002:8000" (см. секцию ports), и системный nginx на сервере тоже
# смотрит на 127.0.0.1:8002 - именно так снаружи работает сайт. Порт
# 8000 нигде на хосте не слушается. Если когда-нибудь поменяешь
# port-mapping в docker-compose.yml - поправь и здесь, и в nginx.

# Currency Analytics - обновление курсов валют
# 00:00, 03:00, 06:00, 08:00, 10:30, 13:30, 16:30, 19:00, 21:00 MSK

0 0 * * * curl -s -X POST -H "X-Admin-Key: $CURRENCY_ANALYTICS_ADMIN_KEY" http://127.0.0.1:8002/api/force-refresh >> /root/currency-analyzer/logs/cron_refresh.log 2>&1
0 3 * * * curl -s -X POST -H "X-Admin-Key: $CURRENCY_ANALYTICS_ADMIN_KEY" http://127.0.0.1:8002/api/force-refresh >> /root/currency-analyzer/logs/cron_refresh.log 2>&1
0 6 * * * curl -s -X POST -H "X-Admin-Key: $CURRENCY_ANALYTICS_ADMIN_KEY" http://127.0.0.1:8002/api/force-refresh >> /root/currency-analyzer/logs/cron_refresh.log 2>&1
0 8 * * * curl -s -X POST -H "X-Admin-Key: $CURRENCY_ANALYTICS_ADMIN_KEY" http://127.0.0.1:8002/api/force-refresh >> /root/currency-analyzer/logs/cron_refresh.log 2>&1
30 10 * * * curl -s -X POST -H "X-Admin-Key: $CURRENCY_ANALYTICS_ADMIN_KEY" http://127.0.0.1:8002/api/force-refresh >> /root/currency-analyzer/logs/cron_refresh.log 2>&1
30 13 * * * curl -s -X POST -H "X-Admin-Key: $CURRENCY_ANALYTICS_ADMIN_KEY" http://127.0.0.1:8002/api/force-refresh >> /root/currency-analyzer/logs/cron_refresh.log 2>&1
30 16 * * * curl -s -X POST -H "X-Admin-Key: $CURRENCY_ANALYTICS_ADMIN_KEY" http://127.0.0.1:8002/api/force-refresh >> /root/currency-analyzer/logs/cron_refresh.log 2>&1
00 19 * * * curl -s -X POST -H "X-Admin-Key: $CURRENCY_ANALYTICS_ADMIN_KEY" http://127.0.0.1:8002/api/force-refresh >> /root/currency-analyzer/logs/cron_refresh.log 2>&1
0 21 * * * curl -s -X POST -H "X-Admin-Key: $CURRENCY_ANALYTICS_ADMIN_KEY" http://127.0.0.1:8002/api/force-refresh >> /root/currency-analyzer/logs/cron_refresh.log 2>&1

# Резервное обновление каждые 2 часа
0 */2 * * * curl -s -X POST -H "X-Admin-Key: $CURRENCY_ANALYTICS_ADMIN_KEY" http://127.0.0.1:8002/api/force-refresh >> /root/currency-analyzer/logs/cron_refresh.log 2>&1

# Очистка логов раз в неделю (воскресенье в 00:00)
0 0 * * 0 find /root/currency-analyzer/logs -name "*.log" -mtime +30 -delete 2>/dev/null

# датой и пересчитать MAE/MAPE (раз в день в 23:50 достаточно). Не
# затрагивает /api/*, отдельная авторизация не нужна.
50 23 * * * cd /root/currency-analyzer && /root/currency-analyzer/venv/bin/python scripts/update_ab_actual_rates.py >> logs/cron_ab_refresh.log 2>&1
